# Extension rule and default reader - brief for the implementer

Written 2026-10-10. Two decisions of the user on that day change the input-format work of `input-format-brief.md`:

1. 'let's use extension for autodetection, otherwise the flag' - the reader is chosen from the file extension, not from the content
2. Detection by extension is the default; no flag is needed for a `.md` or `.html` file

Decision 2 is the third registered exception to the additive policy: numbers for files with the extensions `.md`, `.markdown`, `.html` and `.htm` differ from 1.1.5. With `input_format="plain"` every 1.1.5 number stays bit-identical. The package also takes four findings of the final review (run `wf_73bb512c-5af`) that the review left to the orchestrator.

Rules: the stage B contract of `PRIMER.md` (`make install` once at the end and never `SKIP_VERSION_INCREMENT`, the three gates), no existing test is renamed, no new dependency, no edit to the trackers, the ledgers, the journal or a notebook, no commit, no network request (`HF_HUB_OFFLINE=1` for every real-model step).

## Entries

- **Z1 - the extension rule replaces the content detector** (`ACC-SEGM-93`). Remove `detect_format` and everything that only it uses (its constants, regular expressions and helpers in `src/docdistance/encoders.py`), its tests (`test_detect_format_*` and the tests that exist only for it) and every sentence about it in the documents. Under `auto` the reader of a document is chosen from the file extension, case-insensitive: `.md` and `.markdown` → `markdown`, `.html` and `.htm` → `html`, every other extension and a file without extension → `plain`. A document that is raw text (not a file) → `plain`. The content is not read for the choice. Keep the rule in one small function beside `_read_as` in `src/docdistance/pipeline.py`, with the mapping as one module constant
- **Z2 - `auto` is the default** (`ACC-SEGM-94`). `input_format` defaults to `"auto"` on every pipeline method and one-shot function that takes it, and on the three distance commands. An explicit `plain`, `markdown` or `html` applies to every document of the call. `markdown=True` / `--markdown` alone equals `markdown`. `--markdown` beside an explicitly given other value (also an explicitly given `auto`) is a usage error with exit code 2; `markdown=True` beside an explicitly given other value raises `ValueError`; the command line must tell an option that was given from its default. An unknown value is an error. Every such error is raised before a model loads, also in `distance_wrt_source` and `distance_wrt_source_with_map` (the review found that these two validate after `_ensure_grounding()`). `_seg_kwargs` passes `input_format` only when it differs from the default. The memo key carries the requested value, as today. The marker warning is logged when the reader that ran is `plain`; do not change its text. One DEBUG line per document names the reader and whether the extension chose it
