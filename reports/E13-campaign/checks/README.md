# E13 stage B - check scripts

Scripts behind the real-model readings that the stage B build quotes. Run each from the repository root, which holds `docdistance.json`. Every script that reads a document names the plain reader (`input_format="plain"`, `--input-format plain`), the reader of 1.1.5 and of the stored references; `default-reader/diff.py` reads with the default reader as well and prints the differences.

- `batch-memos/measure.py` - reads the pair files under `data/interim/E12-H67/` and `data/interim/E12-H68/` and the ibm source article; times the `--pairs` batch loop with the memo on and off, takes the sha256 of the nine E12-H67 sweeps under both settings and compares 55 one-shot `distance-wrt-source --json` outputs with the batch lines; writes its outputs to `batch-memos/out/`, which is not kept in the repository: `CI=true .venv/bin/python reports/E13-campaign/checks/batch-memos/measure.py --wait semantic wrt arms oneshot` (further phases: `disjoint-reversed`, `overhead`, `cli-counts`)
- `batch-memos/guardrail_memo_on.py` - reads `baseline/default-path.json.gz`; runs `baseline.py verify --allow moved,n_moved --grounded` with both memos of every `DocDistance` on: `CI=true .venv/bin/python reports/E13-campaign/checks/batch-memos/guardrail_memo_on.py`
- `detail-map/verify_build.py` - reads `detail-map/ref.json.gz` (the 1.1.5 structural details of the six E12-H61 fixtures, the 1.1.5 `moved` flags of the 1680 reorder-pool permutations and the 1.1.5 ibm distances), `data/processed/structure-fixture/` and the ibm summaries; compares the build with them: `CI=true .venv/bin/python reports/E13-campaign/checks/detail-map/verify_build.py build`
- `detail-map/verify_source_map.py` - reads `detail-map/ref_source_map.json` (the 1.1.5 source map and result of the ibm triple gold / adv1-a / source); compares the source map of the build without its added keys: `CI=true .venv/bin/python reports/E13-campaign/checks/detail-map/verify_source_map.py build`
- `offline-load/count_requests.py` - reads the cached models; counts the connections that a child process without `HF_HUB_OFFLINE` opens while it loads the four models with `offline=True`, embeds one text and scores one source-conditioned triple (DEF-DEPS-14): `CI=true .venv/bin/python reports/E13-campaign/checks/offline-load/count_requests.py`
- `solver-cap/cap_readings.py` - reads no file and loads no model, it solves seeded random problems with POT; prints the readings behind the docstrings of `_exact_ot` and `_emd_iter_cap` (DEF-TRANS-9): the result returned at an iteration cap for a 12 x 9 and a 3000 x 3000 problem, the cap at which the 3000 x 3000 problem is solved, and the iterations that `n x 1` and 60000 x 2 problems need: `CI=true .venv/bin/python reports/E13-campaign/checks/solver-cap/cap_readings.py`
- `held-out-readings/readings.py` - reads the 11 ibm summaries, the ibm source, the wergeland source and the metrics files of E15-H78 and E14-H76, and encodes the statements again with the plain reader; prints three readings of the ledger that no notebook computes, each beside its ledger value: the held-out balanced accuracy of the nearest-source flag with each scored foreign statement left out of the calibration, in both directions and under two rules for the cutoff of the own statements (E15-H78), and `DR(D_sel)` of arm a over the shipped pre-pass on the 7 documents not read before registration (E14-H76): `HF_HUB_OFFLINE=1 CI=true .venv/bin/python reports/E13-campaign/checks/held-out-readings/readings.py`
- `default-reader/diff.py` - reads the 55 pairs of `data/interim/E12-H67/allpairs-55.tsv`, the 3 grounded triples of `baseline.py` and the `auto` arm of `reports/E13-campaign/results/E16-H81-metrics-recorded-1.1.21.json` (the E16-H81 metrics as recorded on build 1.1.21); scores each row without `input_format` (the default `auto`, which reads a `.md` file as markdown) and with `input_format="plain"` and prints, per output field of `distance-semantic`, `distance-structural` and `distance-wrt-source`, the number of rows whose two values differ and the largest absolute difference, then how many of the 55 default semantic distances equal the stored `auto` arm (ACC-SEGM-95): `CI=true HF_HUB_OFFLINE=1 .venv/bin/python reports/E13-campaign/checks/default-reader/diff.py 2>&1 | tee logs/extension-default-diff.log`

The two `detail-map` scripts write their reference file in the mode `reference`, which needs the 1.1.5 package first on `PYTHONPATH` (`git archive bd0002e src/docdistance | tar -x -C <dir>`, then `PYTHONPATH=<dir>/src`).
